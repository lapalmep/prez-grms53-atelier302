Résous l'équation

Exemple 1 −5|x + 2| + 13 = −17
−5|x + 2| + 13=−17
− 13− 13
−5|x + 2|=−30
÷ (−5)÷ (−5)
|x + 2|=6
6 ≥ 0 ✓

Une valeur absolue ne peut pas être négative. Ici elle vaut 6, donc c'est possible : deux cas à résoudre.

|x + 2| = 6

Cas 1

x + 2=6
− 2− 2
x=4

Cas 2

x + 2=−6
− 2− 2
x=−8

Interprétation graphique

Les solutions sont les abscisses des points d'intersection : x = −8 et x = 4

−5|x + 2| + 13 = −17

Si x = 4

  1. −5|4 + 2| + 13
  2. = −5|6| + 13
  3. = −30 + 13
  4. = −17 ✓

Si x = −8

  1. −5|−8 + 2| + 13
  2. = −5|−6| + 13
  3. = −30 + 13
  4. = −17 ✓
Ensemble-solutionS = {−8, 4}

Une valeur absolue ne peut jamais être négative. Cette équation n'a aucune solution.

On a multiplié par un nombre négatif : le sens de l'inégalité s'inverse. Comme 20 est positif, il y a des solutions : deux cas.

x > 3 et x < 11  →  3 < x < 11

Interprétation graphique

La courbe est au-dessus de la droite y = 7 lorsque 3 < x < 11

−12|35 − 5x| + 17 > 7

Si x = 7 (dans l'intervalle)

  1. −12|35 − 5(7)| + 17
  2. = −12|0| + 17
  3. = 17
  4. 17 > 7 ✓

Si x = 0 (hors de l'intervalle)

  1. −12|35 − 5(0)| + 17
  2. = −12|35| + 17
  3. = −0,5
  4. −0,5 > 7 ✗
Ensemble-solutionS = ]3, 11[
