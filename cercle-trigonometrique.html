Cours 2 — Chapitre 7

Le cercle trigonométrique

Sur un cercle de rayon 1, les coordonnées de tout point deviennent directement les valeurs du cosinus et du sinus. Ce cercle — appelé cercle trigonométrique — est l'outil central de toute la trigonométrie.

\(P(\theta) = (\cos\theta,\, \sin\theta)\)

Pourquoi rayon = 1 ?
Rappelons que \(\sin\theta = \dfrac{\text{opposé}}{\text{hypoténuse}}\). Sur le cercle trigonométrique, l'hypoténuse est le rayon, qui vaut 1. Donc :
\(\sin\theta = \dfrac{\text{opposé}}{1} = y_{P(\theta)}\)

\(\cos\theta = \dfrac{\text{adjacent}}{1} = x_{P(\theta)}\)
Théorème de Pythagore
Puisque \(P(\theta) = (x, y)\) est sur un cercle de rayon 1, ses coordonnées vérifient toujours :
\(x^2 + y^2 = 1\)
c'est-à-dire \(\cos^2\theta + \sin^2\theta = 1\)

Les angles remarquables : 30°, 45° et 60°

Les coordonnées exactes de ces trois angles se calculent par le théorème de Pythagore. Tout le reste du cercle s'obtient par symétrie.

30° = π/6 rad
\(P\!\left(\dfrac{\pi}{6}\right) = ?\)
Clique pour voir
Côté opposé à 30° = ½ de l'hypoténuse :
\(y = \dfrac{1}{2}\)
Par Pythagore : \(x = \dfrac{\sqrt{3}}{2}\)
\(P\!\left(30°\right) = \left(\dfrac{\sqrt{3}}{2},\dfrac{1}{2}\right)\)
45° = π/4 rad
\(P\!\left(\dfrac{\pi}{4}\right) = ?\)
Clique pour voir
Triangle isocèle → \(x = y\) :
\(2x^2 = 1 \Rightarrow x = \dfrac{\sqrt{2}}{2}\)
\(P\!\left(45°\right) = \left(\dfrac{\sqrt{2}}{2},\dfrac{\sqrt{2}}{2}\right)\)
60° = π/3 rad
\(P\!\left(\dfrac{\pi}{3}\right) = ?\)
Clique pour voir
60° et 30° sont complémentaires → coordonnées inversées par rapport à P(30°).
\(P\!\left(60°\right) = \left(\dfrac{1}{2},\dfrac{\sqrt{3}}{2}\right)\)

Utiliser les symétries

Tout point des quadrants II, III et IV est le symétrique d'un point du quadrant I. Seul le signe des coordonnées change selon le quadrant.

Quadrant cos (x) sin (y) Exemple
I (0° à 90°) + + \(P(60°) = (\tfrac{1}{2}, \tfrac{\sqrt{3}}{2})\)
II (90° à 180°) − + \(P(120°) = (-\tfrac{1}{2}, \tfrac{\sqrt{3}}{2})\)
III (180° à 270°) − − \(P(240°) = (-\tfrac{1}{2}, -\tfrac{\sqrt{3}}{2})\)
IV (270° à 360°) + − \(P(300°) = (\tfrac{1}{2}, -\tfrac{\sqrt{3}}{2})\)

Vérifier qu'un point est sur le cercle

Clique pour voir l'exemple complet.

Le point est-il sur le cercle ?
\(P\!\left(-\dfrac{1}{10},\, \dfrac{3\sqrt{11}}{10}\right)\)
Clique pour voir
On vérifie si \(x^2 + y^2 = 1\) :
\(\left(-\dfrac{1}{10}\right)^2 + \left(\dfrac{3\sqrt{11}}{10}\right)^2 = \dfrac{1}{100} + \dfrac{9 \times 11}{100} = \dfrac{1 + 99}{100} = \dfrac{100}{100} = 1\)
✓ Oui, ce point est sur le cercle trigonométrique.
Astuce

Tu n'as besoin de mémoriser que les 3 angles du quadrant I (30°, 45°, 60°). Tout le reste s'obtient par symétrie en changeant le signe de x (reflet axe des y) ou de y (reflet axe des x), selon le quadrant visé.
